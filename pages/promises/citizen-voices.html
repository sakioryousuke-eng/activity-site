WHY なぜ掲げたのか

一人の困りから、
みんなの課題を見つける。

市民から受ける相談は、最初はその人だけの困りに見えることがあります。

なぜ困っているのか。どのような条件が重なっているのか。同じ条件に当てはまる人はいないか。既存制度ではなぜ解決できないのか。そこまで確かめると、一人の問題に見えたものが、多くの人に共通する制度や仕組みの問題だと分かることがあります。

声の多さだけで、公共性を判断しません。安全、権利、公平性など、人数が少なくても行政が考えるべき重要な問題があります。

MY ROLE / 議員として胸に刻む言葉

市民の言葉を、
行政が扱える政策課題へ翻訳する。

「困っています」という言葉を、そのまま行政へ伝えるだけではありません。原因、影響する人、制度の隙間、公共性、公平性、行政が担うべきこと、地域や民間でできることを整理し、行政が調査・判断・制度検討できる「問い」や「政策課題」へ変換します。それが、この公約に込めた「形にする」の意味です。

HOW I WORK 声を形へつなぐ流れ

聞いて終わらず、その後まで確かめる。

  1. VOICE声を聞く困りや違和感を受け止める
  2. CHECK事実と原因を確かめる現場・資料・制度を確認する
  3. WIDEN影響範囲を見る同じ条件にある人や制度上の影響を見る
  4. JUDGE公共性を考える公平性・必要性・適切な主体を見極める
  5. TRANSLATE政策課題へ翻訳する行政が調査・判断できる問いにする
  6. FORM適切な形へ政策・提案・地域活動などにつなぐ
  7. FOLLOWその後を確認する実際にどうなったかを確かめる

JUDGMENT 声を受け止める責任

声を聞くことと、そのまま要望を通すことは違う。

個別対応が適切なのか、同様の問題があるのか、公平性はあるのか、税金を使う公共性があるのか、行政以外の方法が適切なのかを考えます。すべての要望を同じ形にするのではなく、その声が示す課題に合った方法を探します。

CASE 01POLICY QUESTION / 政策課題への翻訳

日隈小学校・児童クラブと教育環境

ORIGIN / 最初の声

特別な支援を必要とする児童の保護者から、日隈小学校の特別支援学級の教室環境について相談がありました。

CHECK / 公式資料で確認

日田市は「ひのくま放課後児童クラブ」が日隈小学校内の余裕教室2階を使用していると案内しています。学校施設長寿命化計画では、余裕教室を少人数教育などの学びの多様化に対応するスペースや放課後児童クラブに活用し、市内に未活用余裕教室はないとしています。

CHECK / 本人が把握した現場状況

保護者からの相談を受け、本人が現場で把握している状況として、特別支援学級2学級が一つの物理的な教室を使用しています。これは行政公式情報としてではなく、相談・現場確認に基づく把握として記載しています。

TRANSLATE / 政策課題

児童クラブの場所を確保することで、学校教育に必要な空間を圧迫していないか。特別な支援を必要とする児童の個別学習、小集団活動、落ち着いて過ごす環境など、特性に応じた空間を確保できるかを問います。

FORM / 現在の政策案

児童の安全と移動の利便性を確保しつつ、学校教育に必要な教室を将来にわたって圧迫しないため、市内の整備方針を整理し、学校敷地内の校舎外専用施設を基本とする方向が望ましいと考えています。これは国の義務や市の決定事項ではなく、土地、建設費、学校規模、将来児童数、既存施設を踏まえて実現可能性を検討すべき、崎尾本人の現在の政策案です。

STATUS / 現在地

児童クラブと特別支援教育のどちらも子どもに必要です。国も学校教育に支障が生じない範囲で学校施設の活用を進めています。どちらかを悪者にせず、両方に必要な環境をどう確保するか、確認と検討を続けます。
一つの子育て課題を解決するために、別の子どもの学ぶ環境を狭めてよいのか。

CASE 02WIDEN THE ISSUE / 対象を広げる

熱中症対策

ORIGIN / 最初の困り

家庭内の暑さやエアコンを巡る困りは、最初は個々の家庭の問題に見えることがあります。

CHECK / 条件を分ける

年齢、所得、エアコンの有無、購入・設置費、電気代、暑さへの認識など、危険につながる条件を分けて確認します。

TRANSLATE / 政策課題

同じ危険を抱える人がどれくらいいるのか、既存制度からこぼれる人はいないかを整理し、行政が仕組みとして考えるべき対象と課題へ広げます。

FORM / 適切な場所へ

具体的な制度、経過、今後確認することは、重点課題「熱中症対策」で継続して整理します。

STATUS / 現在地

政策環境の進展と本人の成果を混同せず、制度が必要な人に実際に届き、使われているかを確認しています。

CASE 03COMMUNITY ACTION / 自分たちで形にする

子どもの健全育成

政治団体・市議会活動・行政事業ではありません。連合育友会等での議論を起点とした、保護者・地域活動の一環です。

ORIGIN / 問題意識

連合育友会で子どもの健全育成について議論する中、「デジタル社会の中で、子どもたちをどう守るか」という問題意識が出ました。

CHECK / 必要な仕組み

デジタル犯罪や子どもを取り巻く危険は変化が速く、単発の講演や話し合いだけでなく、保護者や地域が継続して学び、実践し、結果を確認して改善できる仕組みが必要だと考えました。

TRANSLATE / 地域で担う課題

行政に求めるだけでなく、保護者と地域が自ら学び、試し、改善を重ねられる土台をつくる課題として整理しました。

FORM / 地域活動

任意団体「日田の健全育成を考える会」を設立。令和8年度「実践・検証」、令和9年度「改善・展開」、令和10年度「継続・市内への波及」の3か年で、実施校が変わっても使える健全育成の仕組みを目指します。

STATUS / 現在地

単年度イベントで終わらせず、実践結果を確かめ、次年度の改善につなぐ地域・保護者活動として進めています。
